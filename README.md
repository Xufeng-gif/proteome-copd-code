# proteome-copd-code

This repository accompanies the manuscript "Plasma Proteins Derived from Airway Epithelial Cells as Predictive Markers of Smoking-Induced COPD".

It contains the core R functions used to specify the lasso Cox protein signature, apply fixed signature weights, and run the counterfactual mediation models for the signature and component proteins.

Data access and release boundaries are described in `DATA_BOUNDARY.md`.
